# ☀️ SolarSentinel-X

## Explainable AI-Driven Predictive Digital Twin Framework for Autonomous Solar Microgrid Health Management

SolarSentinel-X is an AI-powered predictive maintenance system for solar microgrids. It combines Machine Learning, Deep Learning, Explainable AI, and a Digital Twin to continuously monitor system health, predict battery degradation, detect unknown faults, and provide intelligent maintenance recommendations.

---

# Features

- 🌞 Real-Time Solar Microgrid Monitoring
- 🤖 Random Forest Health Prediction
- 🔋 LSTM Battery SOC, SOH & RUL Prediction
- ⚠️ Autoencoder Unknown Fault Detection
- 🧠 SHAP Explainable AI
- 🌐 Digital Twin Simulation
- 📊 Interactive Streamlit Dashboard
- 📡 Live Sensor Visualization
- 📝 Automatic Prediction Logging
- ⚡ Performance Optimized using Streamlit Caching
